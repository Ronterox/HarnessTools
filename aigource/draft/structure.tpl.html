Draft on real data: this repo's aigource/src and aic/aic as they are now, from the Claude Code transcripts. Every change is replayed on the file as it was then (Edit/Write results; command changes lined up with git), so each line of today's code knows the change that wrote it, and each change knows the functions it landed in. A turn is one prompt; a subagent's work counts toward the turn running at that time. Comments are what the agent wrote just before the change, or its latest words in that turn when it wrote nothing then. Partners are what changed in the same turns (at least two). Flags: changed unread, no Read, cat or sed -n of that function (nor an earlier write of it) in the agent's context since its last compaction; untested / failing, no build or test run later in that turn, or the last one failed; corrected, the next prompt reads like a correction; interrupted, you stopped the turn; slow, a file whose agent time per turn is over twice the average file's (time runs between responses, a gap over 5 min counts as 5 min). Rework: lines rewritten within 2 turns of being written (in time order). Fixes: turns whose prompt reports a problem (bug, broken, doesn't work, can't, still, wrong…). Trend: each function's size and complexity right after every change that touched it. Context: what the agent had read (Read, cat, sed -n…) and searched (Grep, Glob, grep, rg…) in the turn before its first change to it. Cost: output tokens and agent time of the responses leading to each change. Age: how long before the last change each of today's lines was written. Owner: the session (by its title) or subagent (by its type and task) that wrote most of today's lines. Turns (bottom strip, [ ]): pick one to see everything that prompt changed, what it read, what the agent said, and how much of its code is still there.
